CHÁ DE CASA NOVA — FERNANDA & CARLA

Como editar rápido:
1. Abra script.js e altere DATA, HORÁRIO e ENDEREÇO.
2. Em script.js, use mostrarLinksLojas: true ou false.
3. Para trocar/adicionar fotos, coloque as imagens dentro da pasta assets e altere o nome do arquivo no index.html.
4. A seção "Nossa História" já está preparada para receber o texto e novas fotos.
5. Abra index.html no navegador para visualizar.

Fontes usadas no site: Great Vibes, Cormorant Garamond e Montserrat.
O site funciona em celular e computador.
